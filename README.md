Code Source
1. Express Generator — Express.js Contributors
Source: https://github.com/expressjs/generator

Used for: Generating the initial Express application structure, including app.js, bin/www, routes/, views/, and package.json. The application uses the Express Generator EJS option.

2. Express Routing — Express.js Contributors
Source: https://expressjs.com/en/starter/basic-routing/

Used for: The routing pattern in routes/index.js, including router.get(...) and res.render(...) to display the Home, About Me, Projects, and Contact Me pages.

3. Express Static Files — Express.js Contributors
Source: https://expressjs.com/en/starter/static-files/

Used for: Serving files from the public directory, including public/stylesheets/style.css and project images under public/images.

4. EJS Templates and Includes — EJS Project Contributors
Source: https://ejs.co/docs/

Used for: EJS view syntax such as <%= title %> and shared header/footer partials using <%- include('partials/header') %> and <%- include('partials/footer') %>.\
